## 1. Анализ рынка подержанных автомобилей

Для запуска онлайн-платформы по продаже подержанных автомобилей необходимо:

- определить факторы, влияющие на стоимость автомобиля;  
- выявить закономерности в данных;
- автоматизировать процесс подготовки данных для аналитики.

Проект состоит из двух частей: аналитического исследования и построения ETL-процесса.


### Часть 1. Анализ данных (Car price prediction model.ipynb)

Проведение факторного анализа формирования цены автомобиля и построение модели прогнозирования его стоимости.

Этапы работы:
1. Очистка данных (обработка пропусков и выбросов); 
2. Предобработка и кодирование признаков; 
3. Exploratory Data Analysis (EDA);
4. Анализ корреляций;
5. Построение модели прогнозирования;
6. Интерпретация результатов и выбор модели с наилучшим результатом предсказания.


### Часть 2. ETL-процесс (Airflow)

Автоматизация процесса загрузки, очистки и подготовки данных. 
Обучение базовых ML-моделей, а также выбор модели с наилучшим результатом предсказания цены.


## 2. Анализ данных по продаже продуктов питания

В рамках проекта был выполнен полный цикл работы с данными – от
подготовки до визуализации:

1. Loginom – этап предобработки/подготовки данных – ETL, очистка. А также RFM/ABC-XYZ анализ.
2. Python + Jupyter Notebook – трансформация расширения полученного в
Loginom файла для эффективности импорта в платформу визуализации.
3. Power BI + DAX – построение интерактивных дашбордов, KPI-метрик и
визуализаций для бизнес-анализа результатов.


## 3. Анализ покупок в 10-ти торговых центрах Стамбула

Для формирования отчёта был использован датасет с Kaggle, проведён его первичный анализ и экспорт в BigQuery с помощью Google Colab, а затем импортирован в Preset для создания визуализаций.
